# AutoLoc

## Objectif du projet

AutoLoc est une application de gestion de location de véhicules.
Elle permet de gérer les véhicules, les clients, les agences et les opérations de location.

## Acteurs

### Client
- Consulter les véhicules disponibles
- Rechercher un véhicule
- Effectuer une demande de location
- Consulter ses locations

### Agent d'agence
- Gérer les clients
- Gérer les véhicules de l'agence
- Gérer les demandes de location
- Enregistrer les opérations de location

### Responsable d'agence
- Superviser l'activité de l'agence
- Gérer les agents
- Consulter les statistiques de l'agence
- Superviser les locations

### Administrateur
- Gérer les utilisateurs
- Gérer les agences
- Administrer l'ensemble de la plateforme
- Superviser les données du système
